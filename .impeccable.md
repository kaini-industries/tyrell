## Design Context

### Users

Cardputer Zero owners using the keyboard and 320 × 170 LCD. For the Catalog,
their task is to browse qualified app identities offline, inspect compatibility
and freshness, and explicitly refresh or download verified bytes. C1 requests
the existing Tyrell UI patterns and preservation of the original M5 Store.

### Brand Personality

Playful, colorful, crafted. The creator-approved retro pixel-art direction is
recorded in `packages/tyrell-chess/.impeccable.md`; reuse that established
personality within the compact native application conventions.

### Aesthetic Direction

Crisp native geometry, compact readable type, deliberate color accents and
obvious keyboard focus. Give catalog rows and detail text priority over
decoration. Use concise state labels for offline, stale, incompatible and
clock-unknown content. A signature or download must never look like an install
approval.

### Design Principles

1. Keep every label and focus indicator readable at native resolution.
2. Show useful keyboard commands in context and retain an immediate exit path.
3. Reinforce color with text and shape, especially for trust and freshness.
4. Open the cached catalog without network access; keep explicit work cancellable.
5. Preserve the M5 Store path and keep package mutation outside this frontend.
