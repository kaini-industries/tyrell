# Store visual assets for 0.1.7

These assets accompany the 0.1.7 candidate, source `src-03a5a269b185`, build
commit `8cba407dcce3675844acc4b203fa78a664044dc3`.

| File | Dimensions | Purpose |
| --- | --- | --- |
| `icon-256.png` | 256×256 | Existing project artwork; unchanged original icon. |
| `01-browser-preview.png` | 320×170 | File-browser UI preview. |
| `02-lcd-player-preview.png` | 320×170 | LCD player with its labeled software example. |
| `03-tracks-preview.png` | 320×170 | Audio/subtitle selection UI preview. |
| `04-hdmi-controller-preview.png` | 320×170 | Handheld HDMI-controller UI preview. |

Each screenshot is a lossless PNG encoding of the actual 0.1.7 builder's P6 PPM
output. No resizing, retouching, added claims or movie frames are included. The
images illustrate the software interface; they are not photographs, TV captures,
performance measurements or proof that the new automatic retry passed hardware
qualification. Keep them labeled as rendered UI previews in the listing.

The 256-pixel icon reuses the existing mechanical resize of the unchanged
80-pixel geometric app icon, covered by the project MIT license. It is not a
new design. `manifest.json` records the current source commit, source PPM
checksums, PNG hashes and dimensions. No old candidate hardware result or
validation status is carried into this asset record.
