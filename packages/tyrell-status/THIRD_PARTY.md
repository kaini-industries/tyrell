# Third-party sources

LVGL 9.5.0 is statically linked, pinned to commit
`85aa60d18b3d5e5588d7b247abf90198f07c8a63` from
https://github.com/lvgl/lvgl . Its MIT license is installed as
`/usr/share/doc/tyrell-status/lvgl-LICENCE.txt`.

The platform design follows M5Stack's MIT-licensed CardputerZero Template,
reviewed at commit `477fa6d217b683e3084c361a757f03dc8ca9f753`:
https://github.com/CardputerZero/Template . This implementation uses the same
LVGL framebuffer backend and read-only Linux evdev pattern, with its own small
status UI, telemetry, CLI and packaging. No vendor firmware or BSP binaries
are bundled in this package.

The optional Linux shell-link pilot implements a limited protocol observed in
Gh0st (`therezor/CardPuterZeroOS`) at commit
`a52c5d78dbeab6dc7fc8e21604b7bbe05d7a35e5`. It uses Tyrell's independently
implemented C++ `Tyrell::ShellLink`, not Gh0st's Rust SDK. The shared MIT license
is installed as `app-common-LICENSE` when the pilot is enabled. See
`docs/shell-link-status.md` in the repository for the supported subset and limitations.

The icon is generated by this project's `assets/make_icon.py`. No external
fonts, images or audio assets are required beyond LVGL's built-in font.
