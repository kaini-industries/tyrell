# Third-party notices

LVGL 9.5.0 is statically linked from locked commit
`85aa60d18b3d5e5588d7b247abf90198f07c8a63`. Its MIT license is installed as
`lvgl-LICENCE.txt`. Its bundled LodePNG decoder retains its separate zlib notice
in `lodepng-LICENSE.txt`.

OpenSSL's crypto library is dynamically linked for in-memory artwork SHA-256.
The backend invokes the operating system's fixed OpenSSL 3 executable for
Ed25519 verification. Debian supplies the runtime and its license notices; this
package does not bundle an OpenSSL library or private key. Development on macOS
uses the documented fixed Homebrew OpenSSL 3 path because system LibreSSL lacks
the required Ed25519 CLI.

Native framebuffer/evdev conventions follow the existing Tyrell Status app and
the MIT-licensed M5Stack CardputerZero Template at
`477fa6d217b683e3084c361a757f03dc8ca9f753`. No vendor executable, firmware, Store
binary or BSP is included.

The packaged seed artwork copies the exact approved Tyrell Status/Video icons,
hash-addressed and checked against the existing Store payload manifests. The
source revision and package identities remain in the signed seed. The Catalog
launcher artwork is generated by this project.
